# WTM - Wind Turbine Maintenance

Настольное приложение для облёта ветропарка дроном. Как с ним работать:

1. Миссия. Создаётся на главной: тип, высота полёта, лимиты погоды, профиль дрона.
2. Ферма и маршрут. Загрузить KML/KMZ с турбинами (или расставить их на карте), построить порядок облёта
   (автоматически, муравьиным или генетическим алгоритмом в фоновом потоке), поправить руками, выгрузить в JSON или KML.
3. Погода. Прогноз Open-Meteo для фермы на 7 дней, ветер на высотах 10-180 м, порывы, окно вылета по часам
   (можно / на грани / нельзя, с причинами) и выбор часа вылета. Оценка времени и заряда по профилю дрона.
4. 3D-облёт. Тот же план полёта, что на карте, в реальном масштабе: высоты транзита и ступиц,
   облёт каждой турбины на безопасной дистанции, скорость и заряд дрона, ротор по ветру в час вылета, карта на земле.
5. Завершить полёт. Миссия фиксируется: полётные данные больше не меняются, профиль дрона сохраняется снимком.
6. Дефекты. Загрузить фото облёта: модель YOLO ищет дефекты прямо на компьютере (WebGPU, иначе WASM),
   большие кадры режутся на плитки, находки привязываются к турбинам по GPS из EXIF, их можно проверить и выгрузить.
7. История. Все миссии с поиском и фильтрами, отчёт в HTML, архив.

Все данные (миссии, фото, находки) хранятся локально в IndexedDB. В сеть уходят только запросы прогноза,
поиск города и тайлы карты.

## Запуск

Нужен [Node.js](https://nodejs.org) 22 LTS или новее.

```bash
npm install
npm run dev              # веб-версия в браузере: http://localhost:5173
npm run dev:electron     # то же в окне Electron
```

Проверки и сборка:

```bash
npm run check            # типы, линтер, тесты, сборка - гонять перед коммитом
npm test                 # только тесты (vitest)
npm run build:electron   # установщик Windows (NSIS) в release/
```

Если установщик не собирается с `EPERM: operation not permitted, rename '...\release\win-unpacked.tmp'`,
это антивирус держит только что распакованный Electron. Можно собрать из уже установленного:

```bash
npx electron-builder -c.electronDist=node_modules/electron/dist
```

## Структура

```
src/
├── domain/        - логика без UI: типы, план полёта, траектория, погода и допуск к вылету,
│                    статусы миссии, маршрутизация (route/), конвейер детекции (detectionPipeline/), всё с тестами
├── lib/           - геометрия (локальные метры от центра фермы, общие для карты, маршрута и 3D), KML, коды WMO
├── storage/       - IndexedDB через Dexie: миссии, профили дронов, фото и находки
├── services/      - Open-Meteo, решатель маршрута и движок детекции (запускают воркеры), разбор фото
├── workers/       - фоновые потоки: маршрут, детекция (onnxruntime-web)
├── features/      - части экранов по функциям: mission, route, weather, forecast, simulation, detection, settings
├── pages/         - экраны (ленивая загрузка)
├── components/    - общие компоненты
├── hooks/         - живые запросы к базе
└── i18n/          - переводы ru/en, переводы функций в i18n/features/<функция>.<язык>.json
electron/          - главный процесс: схема app:// вместо file://, одно окно, внешние ссылки открываются в браузере
public/models/     - модель дефектов (ONNX) и 3D-модель дрона
```

Сторонние модели, данные и их лицензии перечислены в [ATTRIBUTION.md](ATTRIBUTION.md).
