WTM — Wind Turbine Maintenance

Приложение для обслуживания ветряных турбин: загрузка фото лопастей, поиск дефектов, планирование маршрутов дрона, погода и история инспекций.


Быстрый запуск

1. Скачать и установить Node.js (LTS версию): https://nodejs.org
2. Скачать проект: Code → Download ZIP 
3. Открыть папку проекта, в адресной строке проводника написать powershell и нажать Enter
4. В появившемся окне ввести:

npm install
npm run dev


5. Открыть в браузере http://localhost:5173



 Структура папок


src/
├── pages/        — Страницы (Главная, Дефекты, Маршруты, Погода, История)
├── components/   — Кнопки, карточки, модалки (общие детали интерфейса)
├── services/     — Запросы к API (бэкенд)
├── types/        — Типы данных (модели)
├── i18n/         — Переводы (русский / английский)
└── hooks/        — Пользовательские хуки React


 Кому что смотреть

- Фронтенд — src/pages/, src/components/
- Бэкенд — src/services/, src/types/
- Дизайнер — src/pages/
